**Enterprise Network Design Using VLANs and Router-on-a-Stick**



**Project Overview**

This project simulates an enterprise network using Cisco Packet Tracer. The network has three departments: HR, IT, and Finance.



**Network Design**

* VLAN 10: HR Department
* VLAN 20: IT Department
* VLAN 30: Finance Department
* Router: Cisco 2911
* Switch: Cisco 2960
* End devices: 6 PCs



**Technologies Used**

* Cisco Packet Tracer
* VLAN Configuration
* IEEE 802.1Q Trunking
* Router-on-a-Stick Inter-VLAN Routing
* IPv4 Addressing
* Cisco IOS CLI



**Tasks Performed**

* Created three VLANs for department-wise network segmentation.
* Configured switch access ports for the appropriate VLANs.
* Configured an 802.1Q trunk between the switch and router.
* Configured router subinterfaces as default gateways for each VLAN.
* Assigned IPv4 addresses and default gateways to the PCs.
* Tested connectivity using ping.
* Verified configurations using Cisco IOS show commands.



**Verification Commands**

* show vlan brief
* show interfaces trunk
* show ip interface brief
* show ip route
